### 🚀 Featured Projects

#### 🎓 S2dent · Blockchain-Based Academic Credential Platform
My thesis project: a system for issuing, holding, and verifying academic credentials on Ethereum, so they can't be tampered with or forged. I built the **admin dashboard frontend** in a team, working alongside a teammate who built the backend, API, and socket infrastructure.

- Role-based dashboards that follow a four-tier trust chain: **Owner → Academy → Professor → Student**
- Professor and student management with list pages, stat cards, and sort filters
- Credentials dashboard with an "Add New Credential" flow and a **Review & Sign** modal (supports EIP-712 signed data) with a human-readable / actual-data view toggle
- Departments management with inline edit and delete
- Real-time notifications over **Socket.io**

> **Stack:** Next.js · TypeScript · Tailwind CSS · Socket.io · Solidity · Ethereum (Sepolia) · Node.js · PostgreSQL

#### 🖥️ [FBU-CPU](https://github.com/Osama-Alchati/project) · Simple CPU in Verilog
A team project: a 10-bit accumulator CPU with a block-RAM module and a self-checking testbench. It has a 10-instruction set (load, store, add, subtract, multiply, divide, jump, jump-if-zero, halt), a fetch/decode/execute state machine, and three test programs. Includes the project presentation.

> **Stack:** Verilog · Digital Logic Design
